# CANTARIA – Site Institucional (Projeto de Estudo)

## Sobre o projeto

Este projeto foi desenvolvido como um estudo prático para simular um site institucional de uma empresa de construção civil de alto padrão.

O objetivo foi criar uma interface moderna, responsiva e com foco em uma boa experiência do usuário, aplicando conceitos de HTML, CSS e JavaScript em um cenário próximo de um projeto real.

> **Importante:** A empresa, as informações e o conteúdo apresentados neste projeto são fictícios e foram criados apenas para fins de demonstração.

## Funcionalidades

* Layout totalmente responsivo
* Design moderno e minimalista
* Seção de serviços
* Portfólio de projetos
* Depoimentos de clientes
* Sistema de avaliações
* Formulário de contato
* Animações de entrada durante a navegação

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

## Objetivo

Este projeto faz parte do meu processo de aprendizado e da construção do meu portfólio como desenvolvedora front-end.

Ele servirá como base para futuros projetos destinados a clientes reais, incorporando melhorias como:

* Integração com banco de dados (Firebase ou Supabase)
* Sistema de autenticação
* Painel administrativo
* SEO
* Hospedagem em produção
* Domínio personalizado
